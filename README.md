# 🐾 Paws — Destress With Cute Animals

Paws is a Chrome extension that delivers a daily dose of adorable animal photos to reduce stress and boost your mood. A gentle break whenever you need one 🧘‍♀️✨


---

## 🌟 Features

- **Random Cute Animals** — fresh photos every click
- **Save Favorites** — heart & collect images you love
- **Smart Navigation** — hide images you don’t want to see again
- **Fullscreen Viewer** — zoom + pan for full detail
- **Clean & Minimal UI** — calming experience focused on the animals


---

## 🚀 Quick Start

1. Install from Chrome Web Store
2. Get a free API key from **Pexels**
3. Enter your key in the setup screen
4. Start browsing cute animals!

👉 Takes less than 60 seconds!


---

## 🧠 Why Paws?

Research shows that simply **viewing cute animals reduces stress levels** and improves attention.  
Paws gives you mini mindful breaks during the day — especially during stressful work or study sessions.


---

## 🔧 Technology

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Storage:** Chrome Storage API (local)
- **API:** Pexels Photos API
- **Icons:** Font Awesome 7
- **Architecture:** Manifest V3
